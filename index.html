Mesma escala, montadas como a caixa aberta. Passe o mouse para ver a medida; clique duas vezes numa face para ampliar com réguas.

Arraste ou use as setas para girar. A vista 3D mostra só a arte, sem guias.

Passe o mouse numa linha para destacar o elemento no desenho; clique para ir até ele.

Conteúdo obrigatório

Digite as medidas da faca e a ferramenta calcula, face por face, margem, logo, nome, benefícios, pictogramas, código de barras GS1 e texto legal. O resultado sai em escala, em caixa 3D e em planificação, pronto para baixar como guia SVG.
